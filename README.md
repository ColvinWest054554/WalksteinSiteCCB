# WalksteinSiteCCB（福宝AI网站备份仓库站）
<h1>关于此仓库背景：</h1>
<h2>福宝（fubao）</h2>

<p>为FishPort服务器新玩家。进服不久加入共产国际，随后在共产国际内乱中离开（在共产国际期间发表了一些不当智人言论后导致老资历集火），建立沃克斯坦自治区，沃克斯坦共和国等国家及相应的多个AI生成网站（福宝本人无任何编码能力体现）。在制作网站期间<b>不注意网站安全，不审核代码及言论内容，密码明文前端，anon修改新闻权限公开，基本无任何保护</b>。在离开共产国际后对服中老资历大放厥词，在第一次遭到ZBook破解后并不去反思，而是选择无能狂怒，将罪责全部归咎给ZBook及FishPort服务器并辱骂ZBook及FishPort，招致仇恨<br/>

<h2>FishPort-共产国际</h2>

<p>为服中玩家etn618建立的国家。但由于大量招新，新人质量参差不齐。共产国际新人"Jay"在FishPort聊天群用不当态度与服中老资历对话，etn在善后时被Jay职责“只利益，不人民”“法西斯”，同时列举大量现实例子意淫，etn遂开始在共产国际内展开大清洗，将Jay撤职。共产国际后改名芝康武装
<br/>共产国际官网由"福宝"使用AI编写，与沃克斯坦自治区网站结构基本相同，暂未关闭

<h2>FishPort-沃克斯坦自治区</h2>
<p>为FishPort服务器由"福宝"建立的城镇，归属于布里吉斯。<br/>
此城镇于2026年8月1日建立，同日上线网站，风格与共产国际网站类似。8月3日BVVD欺骗福宝"/t delete"为取消圈地指令并执行，导致福宝删除了整个城镇。在删除之后又试图重建城镇，却因服务器同名城镇Bug丢失了城镇银行里的FP，随后再一次解散。其网站管理员密码1111前端明文，被ZBook破解并填充大量网站源码，致使新闻功能无法使用，后停站</p>

<h2>FishPort-沃克斯坦共和国江北市</h2><p>为FishPort服务器由"福宝"建立的国家，首都江北市<br/>
此城镇于2026年8月4日建立，同日<a href="hhttps://jiangbei.pages.dev/">其网站
</a>被ZBook使用anon读写漏洞往新闻栏输入大量<a href="https://cn.bing.com/search?q=%E5%85%B3%E6%B3%A8%E5%A1%94%E8%8F%B2%E5%96%B5">垃圾信息</a>
导致瘫痪，其城镇于8月5日因圈铁路事件解散，现已停站</p>

<h2>FishPort-福宝"FishPort论坛"</h2><p>2026年8月4日由福宝私人搭建搭建，福宝私自冠以FishPort名号的私人论坛，因缺乏审核与管控及匿名导致有人迅速嗅机发表极端反动言论，对FishPort服务器产生负面舆论，后试图逃避责任。现已停站</p>

<h2>8月5日福宝圈铁路事件</h2>
<p>8月5日下午，福宝在江北市附近将其私人铁路圈地并接入河北-山海关跑商主线，致使前往河北-山海关路线的跑商者将改变原有路线直接引入江北市，同时因江北市领地权限设置与铁路设计无法回归正常线路。Wesk随即在全球频道使用激烈措辞警告，要求福宝立即解除圈地，否则将整段拆除河北至山海关的转接路段。福宝最初以“不圈就会被拆”为由抗拒，但最终自行解除了圈地。
<br/>与此同时，曾与福宝有旧怨的etn在争执中亲口承认，他此前出于报复动机“快乐拆毁”了福宝的私人铁轨。福宝借此进一步指控etn618还破坏了河北中转站，并声称握有照片和死亡记录作为证据，但直至福宝退游也并未展示。福宝随后在公屏发送"傻逼服务器""死妈逼服"等语言并在etn城镇插满写有"服务器大傻逼"的告示牌后退游，并同时举报以"谩骂引战""色情低俗"的理由举报服务器Q群，想借此报复服务器。<br/><b>编者注：这一事件并非孤立爆发，而是福宝自8月初建镇以来与多名玩家积怨的爆发，福宝并未意识到自己曾做的事吸引了服务器大部分人的仇恨，招致后来一系列报复</b>
